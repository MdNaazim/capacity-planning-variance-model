# Capacity Planning & Performance Variance Model

**Stack:** Excel (VLOOKUP, SUMIFS, COUNTIFS, AVERAGEIFS, Conditional Formatting, Pivot Table)

A dynamic Excel model that compares **planned capacity** with **actual output** for 42 facilities across 6 regions and
12 months (504 records), and highlights where performance falls short of target.

> **Data note:** all figures are **synthetic** (generated by `build_model.py`, fixed seed). I built regional biases into
> the data on purpose (e.g. South and North-East run below target) so the variance analysis has something to find.

## What's inside `Capacity_Planning_Variance_Model.xlsx`
| Sheet | Purpose |
|---|---|
| `README` | Definitions, assumptions, how to add the Pivot Table |
| `Summary` | Region and monthly variance tables (SUMIFS / AVERAGEIFS / COUNTIFS) + two charts |
| `Targets` | Lookup table: facility -> region and target utilisation; status band assumption (blue = editable) |
| `Data` | 504 facility-month rows. **Blue = inputs, black = formulas**; Region and Target come from `Targets` via **VLOOKUP** |

Conditional formatting: red-white-green colour scale on Variance %, Under / On Track / Over status colours,
data bars on utilisation, red highlight on regions more than 5 points below target.

## Headline results (simulated data)
| Metric | Value |
|---|---|
| Planned capacity / actual output | 1,018,440 / 878,374 units |
| Overall variance | -13.8% (utilisation 86.2% vs 89.2% target) |
| Best region | West: 95.0% utilisation, 1 under-target facility-month |
| Weakest regions | South: 82.0% vs 91.4% target (81% of facility-months under target); North-East: 82.5% |
| Facility-months under target | 195 of 504 (38.7%) |

## Pivot Table
Excel Pivot Tables cannot be generated by code, so add one in the workbook:
`Data` sheet > click inside the table > **Insert > PivotTable** > Rows: `Region`, Columns: `Status`,
Values: Sum of `Planned Capacity` and Sum of `Actual Output`.

## Rebuild
```bash
pip install -r requirements.txt
python build_model.py
```
The workbook recalculates in Excel when any blue input changes.
